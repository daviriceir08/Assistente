* 🌎 Suporte para Português e Inglês

## ⚙️ Recursos

* Nomeação inteligente dos arquivos

## 🔒 Privacidade

Todas as conversas são armazenadas localmente no computador do usuário.

Nenhum dado é enviado para serviços externos, exceto quando a busca na internet estiver ativada.
